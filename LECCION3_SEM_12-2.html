Pasos 1 y 2. Revisar el backup

Objetivo

Leer el contenido del archivo .bak antes de restaurarlo.

RESTORE HEADERONLY
FROM DISK = 'C:\Backups\GradosTitulos_FULL_20261118_1815.bak';
GO

RESTORE FILELISTONLY
FROM DISK = 'C:\Backups\GradosTitulos_FULL_20261118_1815.bak';
GO
  • RESTORE HEADERONLY muestra los datos generales del respaldo: base de origen, tipo y fechas.
  • RESTORE FILELISTONLY lista los archivos que contiene el respaldo.

Dato clave

Del segundo resultado, anota los dos valores de la columna LogicalName (uno de datos y uno de log): GradosTitulos y GradosTitulos_log. Los necesitas en el paso 3.

3

Paso 3. Restaurar como GradosTitulos_Lab

Objetivo

Restaurar el backup completo con otro nombre, sin tocar la base original.

USE master;
GO

RESTORE DATABASE GradosTitulos_Lab
FROM DISK = 'C:\Backups\GradosTitulos_FULL_20261118_1815.bak'
WITH
    MOVE 'GradosTitulos'     TO 'C:\Backups\GradosTitulos_Lab.mdf',
    MOVE 'GradosTitulos_log' TO 'C:\Backups\GradosTitulos_Lab_log.ldf',
    RECOVERY,
    CHECKSUM,
    STATS = 10;
GO
  • MOVE reubica cada archivo lógico a una ruta nueva; usa los valores de LogicalName del paso 2.
  • RECOVERY deja la base lista para usarse al terminar.
  • La carpeta de destino debe existir y SQL Server debe tener permisos de escritura en ella.

Pasos 4 y 5. Verificar estado y tablas

SELECT name AS BaseDatos, state_desc AS Estado, recovery_model_desc AS ModeloRecuperacion
FROM sys.databases
WHERE name = 'GradosTitulos_Lab';
GO

USE GradosTitulos_Lab;
GO

SELECT TABLE_SCHEMA AS Esquema, COUNT(*) AS CantidadTablas
FROM INFORMATION_SCHEMA.TABLES
WHERE TABLE_TYPE = 'BASE TABLE'
GROUP BY TABLE_SCHEMA
ORDER BY TABLE_SCHEMA;
GO

Qué debe aparecer

El estado ONLINE y los esquemas y tablas del proyecto.

Paso 6. Consistencia

DBCC CHECKDB ('GradosTitulos_Lab') WITH NO_INFOMSGS;
GO
  • DBCC CHECKDB revisa la integridad física y lógica de la base restaurada.
  • NO_INFOMSGS oculta los mensajes informativos: si no hay errores, solo se ve que los comandos se completaron.

Paso 7 (opcional). Restaurar FULL + DIFF

Objetivo

Repetir el ejercicio con el backup completo más el diferencial (y luego el LOG, si se tiene). Solo aplica si se cuenta con una cadena de respaldos válida.

Si SQL Server indica que la base está en uso

Problema

Al restaurar sobre GradosTitulos_Lab puede aparecer el error database is in use, porque otras sesiones o pestañas siguen conectadas a la base.

  1. Cierra o cambia esas pestañas. En las pestañas que usan GradosTitulos_Lab, ciérralas o ejecuta USE master;. También colapsa la base en el Explorador de objetos.
  2. Mira quién la tiene y cierra esas sesiones. Desde una pestaña conectada a master (primero la consulta de sesiones, luego el cierre).
SELECT session_id, login_name, program_name, status
FROM sys.dm_exec_sessions
WHERE database_id = DB_ID('GradosTitulos_Lab');
USE master;
GO

DECLARE @sql nvarchar(max) = N'';
SELECT @sql += N'KILL ' + CAST(session_id AS varchar(10)) + N'; '
FROM sys.dm_exec_sessions
WHERE database_id = DB_ID('GradosTitulos_Lab')
  AND session_id <> @@SPID;
EXEC (@sql);
GO

Otra opción es expulsar a los usuarios con ALTER DATABASE GradosTitulos_Lab SET SINGLE_USER WITH ROLLBACK IMMEDIATE;.

Restaurar todo en un solo lote

Sin GO en medio. Así ninguna otra sesión se cuela entre el ALTER y el RESTORE. Selecciona todo y ejecútalo de una vez.

USE master;
GO

ALTER DATABASE GradosTitulos_Lab SET SINGLE_USER WITH ROLLBACK IMMEDIATE;

RESTORE DATABASE GradosTitulos_Lab
FROM DISK = 'C:\Backups\GradosTitulos_FULL_20261118_1815.bak'
WITH REPLACE, NORECOVERY, CHECKSUM, STATS = 10;

RESTORE DATABASE GradosTitulos_Lab
FROM DISK = 'C:\Backups\GradosTitulos_DIFF_20261119_1130.bak'
WITH RECOVERY, CHECKSUM, STATS = 10;

ALTER DATABASE GradosTitulos_Lab SET MULTI_USER;
GO
  • El completo se restaura con NORECOVERY para permitir aplicar otro respaldo después.
  • El diferencial se restaura con RECOVERY, que finaliza la restauración y deja la base en línea.

Si sigue diciendo «database is in use»

SELECT session_id,
       login_name,
       DB_NAME(database_id) AS BaseDatos,
       program_name,
       status
FROM sys.dm_exec_sessions
WHERE session_id IN (64, 68);
GO
