Verificar los archivos físicos de GradosTitulos, identificar sus propiedades de almacenamiento y modificar el modelo de recuperación con SSMS y T-SQL.

Estructura de almacenamiento

ArchivoFunción
MDF (datos principal)Contiene la información principal: estudiantes, docentes, trámites, diplomas, usuarios, roles, permisos y auditoría.
LDF (log de transacciones)Registra operaciones para recuperar ante fallos; permite restaurar a un punto en el tiempo (Full + cadena válida). No es un respaldo ni debe borrarse.
NDF (secundarios)Distribuyen datos, organizan filegroups; no es obligatorio que existan.

ACT 1

Verificar la existencia de la base de datos

SELECT name AS BaseDatos, database_id AS IdBaseDatos,
       state_desc AS Estado, recovery_model_desc AS ModeloRecuperacion,
       create_date AS FechaCreacion
FROM sys.databases WHERE name = 'GradosTitulos';
ACT 2

Identificar los archivos MDF y LDF

USE GradosTitulos;
SELECT file_id, name AS NombreLogico, type_desc AS TipoArchivo,
       physical_name AS RutaFisica, size*8.0/1024 AS TamanoMB,
       max_size, growth, is_percent_growth
FROM sys.database_files;
ACT 3

Consultar propiedades generales

SELECT name, compatibility_level, collation_name, recovery_model_desc,
       page_verify_option_desc, is_read_only, is_auto_close_on,
       is_auto_shrink_on, is_auto_create_stats_on, is_auto_update_stats_on
FROM sys.databases WHERE name = 'GradosTitulos';
ACT 4

Configurar propiedades en SSMS

PropiedadRecomendado
Recovery ModelFULL (si hay política de respaldos del log)
Auto Close / Auto ShrinkFalse
Page VerifyCHECKSUM
Auto Create / Update StatisticsTrue
ACT 5

Cambiar el modelo de recuperación

ALTER DATABASE GradosTitulos SET RECOVERY FULL;   -- Caso A
ALTER DATABASE GradosTitulos SET RECOVERY SIMPLE; -- Caso B
ALTER DATABASE GradosTitulos SET RECOVERY BULK_LOGGED; -- Caso C

BACKUP DATABASE GradosTitulos TO DISK='C:\Backups\GradosTitulos_Inicial.bak'
WITH INIT, COMPRESSION, CHECKSUM, STATS=10;
BACKUP LOG GradosTitulos TO DISK='C:\Backups\GradosTitulos_Log.trn'
WITH INIT, COMPRESSION, CHECKSUM, STATS=10;
ACT 6

Verificar la integridad

DBCC CHECKDB ('GradosTitulos') WITH NO_INFOMSGS;
PRECAUCIÓN: DBCC CHECKDB consume recursos; prográmalo según la carga.
