Automatización de respaldos con SQL Server Agent

ESPEJO COSME JORCH
Emblema del módulo: base de datos y reloj de respaldo (ilustrativo)

Propósito

Implementar una tarea automatizada que realice un respaldo completo diario de GradosTitulos con SQL Server Agent.

Tipos de respaldo y componentes del Agent

ConceptoDescripción
CompletoDatos necesarios para reconstruir la BD
DiferencialCambios desde el último completo
Log de transaccionesRegistros del log pendientes de respaldar
Job / Job StepTarea automatizada / instrucciones a ejecutar
Schedule / Operator / Job HistoryProgramación / notificaciones / historial
NO LO CONFUNDAS: respaldar no es copiar los archivos MDF y LDF. SQL Server Express no incluye SQL Server Agent. La carpeta C:\Backups debe existir en el servidor.
ACT 1

Crear la carpeta de respaldos

C:\
|_ Backups
ACT 2

Respaldo manual

USE master;
BACKUP DATABASE GradosTitulos
TO DISK = 'C:\Backups\GradosTitulos_Diario.bak'
WITH FORMAT, INIT, COMPRESSION, CHECKSUM, STATS = 10;
PRECAUCIÓN: FORMAT e INIT pueden sobrescribir respaldos anteriores.
ACT 3

Respaldo con nombre dinámico

DECLARE @Ruta NVARCHAR(400), @Fecha VARCHAR(20);
SET @Fecha = CONVERT(CHAR(8), GETDATE(), 112) + '_'
           + REPLACE(CONVERT(CHAR(8), GETDATE(), 108), ':', '');
SET @Ruta = N'C:\Backups\GradosTitulos_' + @Fecha + N'.bak';
BACKUP DATABASE GradosTitulos TO DISK = @Ruta
WITH INIT, COMPRESSION, CHECKSUM, STATS = 10;

ACT 5

Crear el Job con T-SQL

USE msdb;
EXEC dbo.sp_add_job @job_name=N'JOB_BACKUP_GRADOSTITULOS', @enabled=1,
     @description=N'Respaldo completo diario de GradosTitulos';
EXEC dbo.sp_add_jobstep @job_name=N'JOB_BACKUP_GRADOSTITULOS',
     @step_name=N'BACKUP_COMPLETO', @subsystem=N'TSQL', @database_name=N'master',
     @command=N'
DECLARE @Ruta NVARCHAR(400);
DECLARE @Fecha VARCHAR(20);
SET @Fecha = CONVERT(CHAR(8), GETDATE(), 112) + ''_''
           + REPLACE(CONVERT(CHAR(8), GETDATE(), 108), '':'', '''');
SET @Ruta = N''C:\Backups\GradosTitulos_'' + @Fecha + N''.bak'';
BACKUP DATABASE GradosTitulos TO DISK = @Ruta
WITH INIT, COMPRESSION, CHECKSUM, STATS = 10;',
     @on_success_action=1, @on_fail_action=2;
EXEC dbo.sp_add_schedule @schedule_name=N'SCH_BACKUP_DIARIO_GRADOSTITULOS',
     @enabled=1, @freq_type=4, @freq_interval=1, @active_start_time=020000;
EXEC dbo.sp_attach_schedule @job_name=N'JOB_BACKUP_GRADOSTITULOS',
     @schedule_name=N'SCH_BACKUP_DIARIO_GRADOSTITULOS';
EXEC dbo.sp_add_jobserver @job_name=N'JOB_BACKUP_GRADOSTITULOS';
ACT 6

Ejecutar manualmente el Job

USE msdb;
EXEC dbo.sp_start_job @job_name = N'JOB_BACKUP_GRADOSTITULOS';
ACT 7

Verificar el historial

USE msdb;
SELECT TOP (20) J.name, H.step_name, H.run_date, H.run_time,
       H.run_duration, H.run_status, H.message
FROM dbo.sysjobhistory H JOIN dbo.sysjobs J ON H.job_id = J.job_id
WHERE J.name = 'JOB_BACKUP_GRADOSTITULOS' ORDER BY H.instance_id DESC;
run_status: 0 Failed · 1 Succeeded · 2 Retry · 3 Canceled · 4 In Progress
ACT 8

Verificar el archivo de respaldo

RESTORE HEADERONLY FROM DISK = 'C:\Backups\GradosTitulos_Diario.bak';
RESTORE FILELISTONLY FROM DISK = 'C:\Backups\GradosTitulos_Diario.bak';
RESTORE VERIFYONLY FROM DISK = 'C:\Backups\GradosTitulos_Diario.bak' WITH CHECKSUM;
PROFESIONAL: VERIFYONLY no reemplaza una prueba real de restauración.
